# Blink Chat

The future of real-time communication. Built with React, Vite, and Firebase.

## Features
- **Real-time Messaging**: Instant text chat using Firebase Realtime Database.
- **Voice & Video Calls**: Peer-to-peer WebRTC calls via Mirotalk integration.
- **Communities & Channels**: Organize conversations into dedicated spaces.
- **Zero-Trust Security**: Continuous background authentication and strict security rules.
- **Moderation Tools**: Robust administrative tools including channel management, member banning, and message pinning.
- **File Sharing**: Ephemeral 100MB file sharing powered by tmpfiles.org.

## Tech Stack
- Frontend: React 18, Vite, React Router, Vanilla CSS (CSS Modules)
- Backend: Firebase Auth, Firestore, Firebase Realtime Database

## Getting Started
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Add your Firebase configuration to `.env`.
4. Run `npm run dev` to start the development server.
